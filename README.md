## Installation

### 1. Clone the repository

```bash
git clone https://github.com/subham-khandual/swasthya-setu.git
cd swasthya-setu
```

### 2. Setup frontend

```bash
cd frontend
npm install
```

### 3. Setup backend

```bash
cd ../server
npm install
```

### 4. Environment variables

Create `.env` files for both frontend and backend as needed.

#### Frontend example

```env
REACT_APP_API_URL=http://localhost:5000/api
```

#### Backend example

```env
MONGO_URI=your-mongo-db-uri
PORT=5000
```

### 5. Run the application

#### Start backend

```bash
cd server
npm start
```

#### Start frontend

```bash
cd frontend
npm start
```

The application runs locally on:
- Frontend: http://localhost:3000
- Backend: http://localhost:5000
